# 02 · Vetting scorecard

Score each creator 1–5 on each line. Shortlist anyone at **28+ out of 40**, and never proceed with a fail on brand safety.

| Criteria | What to check | Score (1–5) |
|---|---|---|
| **Audience fit** | Do their followers look like our buyer (age, location, interests)? Ask for audience insights screenshots. | |
| **Audience location** | Is most of the audience in our target market? | |
| **Real engagement** | Comments are specific and genuine, not emojis and spam | |
| **Views vs followers** | Recent average views are healthy relative to follower count | |
| **Content quality** | Strong hooks, clear speaking, good lighting and audio | |
| **Ad-readiness** | Would their content work as a paid ad? Have they done partnership ads before? | |
| **Brand fit** | Tone and values match ours | |
| **Reliability** | Professional replies, meets deadlines, clear rates | |
| **Total** | | **/40** |

## Brand safety: pass or fail

- [ ] No recent content that conflicts with our values or category
- [ ] No exclusivity with a direct competitor
- [ ] Discloses paid partnerships properly
- [ ] No signs of bought followers or engagement (sudden follower spikes, mismatched engagement)

## Red flags

- Follower count high, views consistently low
- Comments that don't relate to the content
- Audience mostly outside the target market
- Unwilling to share audience insights
- Won't agree to paid usage terms in writing
