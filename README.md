# Influencer Playbook

**Creator sourcing, vetting and outreach, built for paid use from day one.**

Most influencer campaigns are judged on likes. I treat creators as a performance channel: the content has to work organically **and** as an ad (see [whitelisting-playbook](https://github.com/vidhyaganapathy/whitelisting-playbook)).

---

## Principles

- **Audience fit beats follower count.** A small creator your buyer trusts beats a big one they don't.
- **Brief for paid from day one.** Agree paid usage before filming.
- **Run creators as a portfolio.** Test several, scale the winners.
- **Track everything.** Every creator gets a UTM, a code or a tracked link.
